# Portfolio site — Md Mahfuzur Rahman

Single-file bespoke portfolio (`index.html`) for GitHub Pages.

## Deploy
1. Create a public repo named `YOURUSERNAME.github.io`
2. Put `index.html`, `docs/`, and `images/` in the root
3. Settings → Pages → Branch: `main` / `root` → Save
4. Live at `https://YOURUSERNAME.github.io`

## Before you publish — edit these placeholders in index.html
- Social links (search for `https://scholar.google.com/`, `https://orcid.org/`,
  `https://github.com/`, `https://www.linkedin.com/`) — paste your real URLs
- Add `images/portrait.jpg` (a headshot ~400x400) — the hero auto-hides it if missing
- The four CV/résumé PDFs are already wired up in `docs/`

## Iterate with Codex
Feed the current index.html back with focused requests, e.g.
"add a research-figure image beside thread iii", "tighten mobile spacing".
